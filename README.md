# PyTorch Tutorial

A collection of Jupyter Notebooks covering the fundamentals of **PyTorch and Deep Learning**.  
This repository is created as a hands-on learning resource to understand PyTorch concepts through practical examples and implementations.

## 📚 Contents

The repository covers the following topics:

### 1. PyTorch Tensors
- Creating tensors
- Tensor attributes and operations
- Tensor indexing and slicing
- Mathematical operations
- CPU and GPU operations

📓 `Pytorch_Tensors.ipynb`

### 2. Neural Networks
- Understanding neural network fundamentals
- Building neural networks using PyTorch
- Forward propagation
- Loss functions
- Backpropagation
- Model training

📓 `Pytorch_NN.ipynb`

### 3. Neural Network Modules
- Using `torch.nn.Module`
- Creating custom neural network architectures
- Layers and parameters
- Training neural network models

📓 `Pytorch_NN_module.ipynb`

### 4. Automatic Differentiation (Autograd)
- Understanding gradients
- Computational graphs
- `requires_grad`
- Backpropagation using PyTorch Autograd

📓 `Pytorch_Autograd.ipynb`

### 5. Optimization
- Understanding optimizers
- Gradient Descent
- Optimizer implementation in PyTorch
- Training models using optimization algorithms

📓 `Pytorch_Optuna.ipynb`

### 6. Convolutional Neural Networks (CNN)
- Understanding CNN architecture
- Convolution layers
- Pooling layers
- Activation functions
- Building and training CNN models
- Image classification

📓 `Pytorch_CNN.ipynb`

### 7. CNN with Transfer Learning
- Introduction to Transfer Learning
- Using pretrained models
- Fine-tuning pretrained networks
- Applying Transfer Learning to image classification

📓 `Pytorch_CNN_Using_Transfer_Learning.ipynb`

### 8. Artificial Neural Networks (ANN)
- Building ANN models using PyTorch
- Model architecture
- Training and validation
- Classification using neural networks

📓 `Pytorch_ANN.ipynb`

### 9. ANN with Fashion-MNIST
- Fashion-MNIST dataset
- Image classification
- Training an ANN model
- GPU-based model training

📓 `Pytorch_ANN_fashion_mnist_gpu.ipynb`
